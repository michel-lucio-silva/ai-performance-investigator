# AI Performance Investigator

Investigacao de performance de APIs

## Tecnologias
- C# e ASP.NET Core 8
- API REST
- OpenAI API (opcional)
- Interface HTML, CSS e JavaScript

## Executar
`powershell
dotnet run
`

Acesse a URL local apresentada no terminal.

## Configurar IA
Defina OPENAI_API_KEY como variavel de ambiente.
Sem chave, a API funciona em modo demonstrativo.

## Endpoints
- GET /api/health
- POST /api/analyze
